# AMUG 0.3.0

First stable local-first controller for VSITOO S6 Plus.

## Highlights

- Exact 120–150°F control with device readback confirmation
- Built-in and personal drink presets
- Empty safety interlock plus manual verified safety stop
- 5–120 minute timer plus firmware-backed 2/4-hour failsafe
- Temperature palette, six music modes, hold/charging lights
- Local ETA/trend, overshoot, runtime, and preference insights
- Tile, widget, opt-in alerts, multi-mug support, local history
- No account, cloud, analytics, ads, or Internet permission
